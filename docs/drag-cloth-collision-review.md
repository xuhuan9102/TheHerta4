# 穿脱碰撞复查（2026-11-14，未通过完整验收）

本文是当时的失败候选记录。当前生成器、冻结随动与已接受的效果范围见[使用说明](drag-cloth.md)。

本次复查使用删袖后的工程重新完整导出，保持游戏模组移除。下述对照候选都在
`ModBackups` 中运行，没有安装，也没有将候选求解器写入生成器。

## 已复现的问题

生成的 INI/HLSL 在独立 D3D11 设备上执行，输入使用抓帧的387骨骼矩阵，对新网格
重新蒙皮。剩余衣物、身体权重和骨骼映射与此前捕获相符；没有切片复用旧 SO。
新 Component 有12691个渲染顶点行，上衣代理1559点、3030面。

1. **贴合分区会受衣物开口变化影响。** 删除袖子而保持身体不变后，1112/1559个
   上衣代理点被归为不参与躯干滑移的过渡点，其中包括442/537个胸前测试点。
   仅修正碰撞法向不能弥补错误的初始分区。
2. **最近面的法向不能判定多个身体表面的联合内部。** 对该姿态的1650个上衣渲染点，
   原生输入有120点位于身体联合内部；最近几何面法向把其中45点判在外部。
   限位/分类对照在满行程仍有124个体内点，其中40点同样被漏判。
   三方向有向射线的多数判定在这两组点上均与独立绕数判定一致。
3. **现有点修正与面修正不能替代共同的约束求解。** `FaceGlobal` 修正后，`Edges`
   仍会修改位置；最后的粒子修正又可能单独移动一个角，重新破坏三角面或产生拉丝。
   给当前循环简单增加次数并没有解决这一矛盾。
4. **当前移动路径缺少完整的三角面连续接触检查。** 法线挤出路径的检查只限制褶皱
   偏移，不能覆盖 `Predict`、材料滑移、边约束、动画输送及渲染重建的全部运动。
5. **静置超时不是接触收敛。** 当前强制静置条件可能在残留碰撞时休眠。
   检查缓冲健康、固定点没有移动或少执行了派发，都不能证明穿脱正确。

原生输入本身有148个与身体相交的上衣渲染面。这不能为运行时新增的相交开脱；
初始化解穿透与阻止新穿透需要分别验证。最近面距离也不等于到联合体外部的距离。

## 对照结果

以下使用相同的新网格、捕获姿态与100%行程；分类诊断保持同一身体的参考分区。
这些是定位原因的对照，不是通用衣型识别已修好的声明。

| 候选 | 新增相交面 | 拉伸超过3倍的面 | 结论 |
| --- | ---: | ---: | --- |
| 腋下终点与分类对照 | 163 | 22 | 未通过 |
| 末段8轮面/点接触，移除末段边求解 | 80 | 99 | 穿插减少、拉丝加重，拒绝 |
| 增加点移动路径检查 | 133 | 31 | 点路径不足以覆盖面穿透，拒绝 |
| 路径检查、联合体内判定、允许锚点解穿透 | 80 | 51 | 未通过 |
| 在联合判定基础上交替执行8轮材料/面/点接触，再检查接触 | 32 | 40 | 仍未通过 |

联合判定候选的体内顶点降为0，但仍有97个面与身体相交，包含80个新增相交面；
51个面拉伸超过3倍，最大边长比例约9.77。其求解器健康值仍然为1，非衣物输出
未变、回零也能精确恢复原生数据。这直接说明此前的成功信号不足以验收几何效果。

最后的交替求解对照进一步降到50个相交面、32个新增相交面，体内顶点保持0；但仍有
40个面拉伸超过3倍，最大比例约11.10，不能接受为修复。单纯增加当前投影循环的次数，
尚未建立完整三角面连续接触或接触/材料的共同收敛保证。

三方向射线适合进一步验证联合内部判定，不应将本次验证直接解读为任意开口、
反向或损坏碰撞网格均有可靠的实体内部定义。

## 下一版求解器应保持的约束

需要同时求解衣物形状与身体接触，避免继续叠加独立的最近点推离补丁：

- **贴合身份与阻挡分离。** 身体绑定分区、三角形ID和邻接决定贴合与权重；整个身体
  都能阻挡。排斥到手臂不能把躯干衣片改绑到手臂。身体分区不能因删除袖子而改变。
- **保留材料约束。** 衣口和袖口是材料目标，接触约束不能简单跳过这些点，也不能
  为了排出一个点无限拉长相邻边。两种约束冲突时应缩短可接受的控制行程。
- **提议、检测、求解、验收、提交。** 从最后接受的衣物状态生成目标，检查顶点/面、
  边/边的连续接触，把伸长、弯曲和碰撞作为同一求解循环。最终渲染重建后仍检查整面。
  面中心采样可以补充诊断，不能代替整面检查。
- **不可行时停止前进。** 腋下没有足够空间时，降低本次可接受的拖动量，保持最后
  接受状态。不能把衣片推向另一侧表面，也不能回退成全穿的原生输出。固定终点只是
  其中一项限制，不替代身体碰撞。
- **动画与休眠有独立约束。** 最后接受状态必须由当前骨架输送，不能直接复用旧的
  世界坐标；身体的运动也参与连续接触检测。接触残差和形状残差达标后才能休眠，
  不能用固定帧数或超时掩盖未解决的碰撞。

原生 SO 前缀复制、Deform pass 骨架快照、TTL 重绑定后的发布链路与普通拖拽碰撞
不应随这次求解器调整而改写。三个区域的衣物状态与接受的控制量仍应各自独立，
仅共享身体输入。衣物自碰撞保持独立选项。

## 可重复运行的几何检查

新增 `tools/check_drag_cloth_mesh.py`，直接检查实际生成链的回放 NPZ：

```powershell
python tools/check_drag_cloth_mesh.py replay.npz --report result.json
python -m unittest tests.test_drag_cloth_mesh -v
```

输入为 `source`、`output`、`mask`、`body`、`triangles`；可选 `state` 只用于报告健康值。
检查实际渲染三角面相交、完整嵌入身体的点、拉伸与非衣物输出，不复用求解器的
BVH、贴合分区或法向。体内判定使用独立的三角形立体角绕数。
输出仍有穿透时返回退出码1，即使新增相交为0或健康值为1也不会通过。

该检查是静态几何检查，不证明移动过程中没有隧穿，也不证明拖动行程、间隙毫米值、
动画表现或性能已经正确。它必须与逐帧运动、完整行程、三种衣物和不同姿态回放共同使用。
