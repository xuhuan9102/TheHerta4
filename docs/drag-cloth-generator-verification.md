# 拖拽生成器检查（2026-11-15）

用户已确认当前「蕾米埃尔·月夜密语」效果暂时可用。本次整理并验证生成器，保持现有穿脱行为，
不把生成检查通过解释成任意姿态都无穿模。

## 修正与整理

- 普通碰撞与穿脱独立生成，区域衣物/身体选择、行程箭头、左右袜与双腿短裤分区保留。
- 停住或松手冻结最后模拟网格，动作仅输送蒙皮；两个绘制槽分别保存代理和显示缓存。
- 修正接触查询失败时旧双腿缓存仍可被重新提交的问题；先验证失败用例，再修正并通过回归。
- 修正D3D11检查工具对普通拖拽组件的初始化兼容，未启用穿脱时不要求穿脱组件元数据。
- 参数说明与当前调度保持一致。当前指南、设计决策和历史候选记录分开。
- 增加`tools/check_drag_cloth_export.py`，重复检查产物哈希、文件/衣物段引用、缓冲容量、写回别名和活动CS编译。

## 重复检查

当前配置与计算流程见[使用说明](drag-cloth.md)，产物可独立运行：

```powershell
python tools/check_drag_cloth_export.py MOD_DIRECTORY --compile --report export-audit.json
python tools/check_drag_cloth_mesh.py replay.npz --report mesh-audit.json
python -m unittest tests.test_drag_cloth_export tests.test_drag_buffer_bindings tests.test_drag_feature_switches
```

`export-audit.json`只表示包结构和着色器检查，`geometry_certified`始终为false；
实际形变需另行回放，网格检查失败时不能用编译成功覆盖结果。
