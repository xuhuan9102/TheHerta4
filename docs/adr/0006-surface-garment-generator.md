# 0006 - 可选的实时贴身穿脱生成

- 状态：implemented（生成器与生成产物的 D3D11 回归覆盖；游戏实验验证来自丽娜模组）
- 日期：2026-11-07
- 关联：[普通拖拽整面碰撞](0005-drag-parallel-surface-constraints.md)

## 开关与适用范围

拖拽交互节点增加 `cloth_slide_enabled`，默认关闭。它与 `collision_enabled` 独立：
普通碰撞关闭时仍能生成穿脱自己的身体碰撞与贴合资源；穿脱关闭时不发射其资源、
命令列表或热键，并按生成清单清理旧的自有文件。两项都不改变形态键/面板联动开关。

当前穿脱需要 ZZMI 家族的合并骨架、可确定的当前帧蒙皮输出、四权重/四 uint 索引，
以及 float3 position/normal、float4 tangent 的顶点布局。其他尾随顶点属性保留原字节。
EFMI 不借用这套 ZZMI 输出协议。无效配置明确失败，不能生成猜测的 G1/cid=0 引用。

## 几何生成

生成器读取实际导出的 Position、Blend、索引和物体注释。可指定穿脱衣物集合与身体
碰撞集合；未指定时沿用区域的包含物体与碰撞体列表。衣物与身体不得共用所选顶点。

按位置焊接衣物材质缝并移除重复面，再按拓扑连通部分生成独立求解器。连裤袜这样的
连通部分共享一个目标；分开的袜子使用不同目标和命中映射。代理超预算时执行保持
拓扑的端点 QEM 简化，显示网格通过代理三角形的重心坐标和局部形变梯度重建，
并不减少原渲染网格。默认代理上限 2450，袜口上限 128，以满足单线程组共享内存预算。

生成的静态数据包括代理拓扑、拉伸/弯曲距离约束及着色批次、面着色批次、邻接、
袜口支撑线、显示映射、身体三角形顺序、表面有效位与固定解剖归属。它们描述当前
模型的绑定几何，不是穿脱档位或预制姿态。

## 运行时顺序

1. 从产物推导所属 SkeletonGroup 与出现次计数器。生成器在写出衣物所在顶点行的
   直接绘制、SO 重放或蒙皮计算派发之前，记录目标缓冲并复制该次使用的骨架矩阵。
   每个组件和实例槽分别保存快照。后续部件可以继续更新合并骨架池，穿脱读取和
   顶点配对的快照。关闭生成开关时移除对应的捕获命令与资源。
2. 将当前蒙皮输出复制到私有可读 NativeInput；将当前绑定位置与命中信息分别转换成
   明确步长的可读结构化视图。原始 UAV-only Position 和 typed 命中缓冲不能直接
   假定为结构化输入。
3. 从同一 NativeInput 重建共享身体 BVH。每件衣物读取自己的拓扑与表面归属，
   选择与当前蒙皮输出匹配的骨架快照，执行输入控制与几何就绪检查。
4. 全穿时以及首次开始下拉时，代理从当前可见模型重新对齐。未完成的几何、失败的
   pass 都不能提交初始化标记。实例标记携带本轮 epoch，不能只看粒子零的旧标记。
5. 当前接触与动态 top-4 权重输送动画；三个子步交替求解张力/弯曲、有序收拢、
   身体表面滑移和速度限制。材料压缩量驱动连续程序化褶皱，袜口由当前身体截面求得。
6. 粒子自分离后，再执行两遍着色的整面身体接触约束，最后更新接触与动态权重。
7. 只写衣物对应的输出行。输出是普通可作 VB 的缓冲，绘制步长与顶点结构一致；
   写入通过同一内存上的 R32_FLOAT、4 字节别名，不能把顶点步长直接当 UAV 元素步长。
8. 绘制前发布结果，TTL 内层旧 vb0 重绑之后再次发布。绘制后恢复原生 VB0/VB2。
   代理动态权重用于随动画搬运接触，不能把已蒙皮输出再次整体蒙皮。

原生输出每组件/实例/帧复制一次，衣物在同一输出上写互不重叠的行。未命中的独立
衣物不改变目标。运行时关闭穿脱时不执行该链，普通拖拽及其碰撞继续使用原路径。
生成的着色器展开包含文件，几何常量变化会更新根文件，避免命中旧的编译缓存。
内容相同时不改写根文件和静态缓冲，保留 3Dmigoto 缓存时间戳。

## 边界

这是贴身穿脱近似，采用程序化褶皱和粒子自分离，不是完整的自由布料及三角面自碰撞。
脚部固定，不保证完全脱出脚部。原模型穿插、缺失碰撞面和错误的衣物选择不能靠开关
自动修复。普通拖拽的整面位移比例方法继续独立存在，不替代此穿脱求解器。

详细参数和检查方法见 [使用与计算流程](../drag-cloth.md)。
